Phone Cooling System / نظام تبريد الهاتف
=====================================
افتح الملف index.html بالضغط عليه مرتين (يعمل في أي متصفح، بدون إنترنت أو سيرفر).
Open index.html in any browser. No server or install needed.

index.html  - الصفحة / the page
style.css   - التصميم / styles
script.js   - المحاكاة واللغتين العربية والإنجليزية / simulation and English-Arabic text

ملاحظة: الخطوط تُحمَّل من Google Fonts، فبدون إنترنت يستخدم المتصفح خطوطًا بديلة وكل شيء يعمل.
This is an educational prototype. All temperature, charging and cooling values are simulated.
